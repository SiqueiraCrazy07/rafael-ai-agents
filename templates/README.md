# Templates

## Objetivo

Guardar modelos reutilizaveis para agentes, workflows, decisoes, relatorios e documentacao operacional.

Templates reduzem variacao desnecessaria e facilitam reaproveitamento entre produtos como PromoClub007, frentes de PM, UX, QA, analytics e automacao.

## Como usar

1. Escolha o template apropriado.
2. Copie a estrutura para o destino correto.
3. Preencha todos os campos obrigatorios.
4. Remova instrucoes que nao se aplicam.
5. Revise riscos, escopo e criterios de qualidade.

## Exemplos

- `agent-template.md`: padrao unico para novos agentes.
- Futuro `workflow-template.md`: padrao para workflows operacionais.
- Futuro `decision-template.md`: padrao para decisoes versionadas.

## Boas praticas

- Preferir campos claros a textos longos.
- Manter templates genericos, mas acionaveis.
- Nao incluir dados sensiveis.
- Atualizar templates quando o padrao operacional mudar.
- Usar o mesmo vocabulario em agentes, playbooks e workflows.
