# Docs

## Objetivo

Centralizar documentacao tecnica, arquitetura, operacao, integracoes e decisoes de alto nivel do Agent Operating System.

## Como usar

1. Consulte `agent-operating-system.md` para entender a estrutura geral.
2. Consulte documentos especificos por tema.
3. Atualize documentacao junto com mudancas operacionais relevantes.
4. Evite duplicar decisoes em varios arquivos sem referencia cruzada.

## Exemplos

- `architecture.md`: arquitetura conceitual inicial.
- `roadmap.md`: roadmap geral.
- `agent-operating-system.md`: modelo operacional do repositorio.
- `google-sheets-integration.md`: integracao real com Google Sheets.
- `frontend-cache-integration.md`: plano de consumo do cache pelo frontend.

## Boas praticas

- Manter documentos objetivos e rastreaveis.
- Declarar premissas e riscos.
- Atualizar docs quando workflows mudarem.
- Nao documentar segredos.
- Preferir links para artefatos relacionados.
