# Metrics

## Objetivo

Definir metricas operacionais para acompanhar confiabilidade, produtividade, qualidade e resultado dos agentes e workflows.

## Metricas recomendadas

- taxa de sucesso de workflows;
- tempo medio de execucao;
- quantidade de falhas por conector;
- quantidade de deploys bloqueados;
- quantidade de ofertas processadas;
- taxa de dados rejeitados;
- tempo ate resolucao de incidente;
- quantidade de decisoes registradas.

## Boas praticas

- Separar metrica operacional de metrica de produto.
- Definir dono para metricas criticas.
- Evitar metricas sem acao associada.
- Registrar origem e frequencia de coleta.
