# Runtime Policies

Camada de politicas autonomas do runtime.

O objetivo e transformar sinais de aprendizado, supervisor e memoria operacional em decisoes acionaveis antes ou durante uma execucao.

Na V1, as politicas geram artefatos em:

- `runtime-data/policies/`
- `memory/policies/`

Isso permite auditoria, rastreabilidade e integracao futura com roteamento, fila, supervisor e self-healing.
