# Projects

## Objetivo

Mapear produtos e iniciativas que usam o Agent Operating System.

Cada projeto deve indicar agentes envolvidos, workflows, riscos, decisoes relevantes e proximos passos.

## Como usar

1. Crie um arquivo por projeto.
2. Liste objetivos e escopo.
3. Relacione agentes aplicaveis.
4. Relacione workflows e conectores.
5. Registre riscos e proximos agentes recomendados.

## Exemplos

- `promoclub007.md`: projeto de ofertas, vitrines, automacao e afiliacao.
- Futuro `pm-operating-system.md`: gestao de produto e discovery.
- Futuro `analytics-platform.md`: metricas e dados.

## Boas praticas

- Manter o mapa do projeto atualizado.
- Evitar duplicar conteudo dos agentes.
- Registrar dependencias externas.
- Separar roadmap de execucao atual.
- Linkar playbooks e docs relevantes.
