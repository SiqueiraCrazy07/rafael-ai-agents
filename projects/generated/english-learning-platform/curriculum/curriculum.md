# Curriculum

## Objectives
- build durable recall through retrieval practice
- increase fluency through short repeated sessions
- progress only after mastery evidence
- adapt difficulty from learner performance

## Levels
- foundation: understand core concepts and vocabulary (80%)
- practice: apply skills with guided feedback (85%)
- fluency: perform with less scaffolding and mixed practice (90%)

## Modules
- diagnostic quiz: diagnostic -> guided practice -> active recall -> mixed review -> mastery check
- daily micro-lessons: diagnostic -> guided practice -> active recall -> mixed review -> mastery check
- vocabulary review: diagnostic -> guided practice -> active recall -> mixed review -> mastery check
- learner dashboard: diagnostic -> guided practice -> active recall -> mixed review -> mastery check
