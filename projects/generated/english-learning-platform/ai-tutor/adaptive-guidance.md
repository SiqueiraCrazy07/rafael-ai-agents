# Adaptive Guidance

## difficulty

- start with guided examples
- increase challenge after mastery evidence
- return to review mode after repeated errors

## tone

clear, reflective and goal-oriented

## explanation

step-by-step with optional deeper rationale

## speed

self-paced with recap checkpoints

## depth

concept, example, application and reflection

## recommendations

- one guided retry
- one independent challenge
- one recall prompt
- one reflection question
