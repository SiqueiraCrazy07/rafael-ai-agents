# UX Specification

## Personas
- Owner: understand product value and operational metrics
- Operator: run daily workflows with minimal friction
- End User: complete the core task quickly and confidently
- Learner: practice, receive feedback and improve over time
- Instructor: track progress and identify learning gaps

## Screens
- onboarding
- home dashboard
- detail view
- settings
- analytics
- lesson player
- practice review
- mastery map
