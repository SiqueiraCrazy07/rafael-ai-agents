# Curriculum

## Objectives
- build durable recall through retrieval practice
- increase fluency through short repeated sessions
- progress only after mastery evidence
- adapt difficulty from learner performance

## Levels
- foundation: understand core concepts and vocabulary (80%)
- practice: apply skills with guided feedback (85%)
- fluency: perform with less scaffolding and mixed practice (90%)

## Modules
- core mechanic: diagnostic -> guided practice -> active recall -> mixed review -> mastery check
- 3 levels: diagnostic -> guided practice -> active recall -> mixed review -> mastery check
- score feedback: diagnostic -> guided practice -> active recall -> mixed review -> mastery check
- learning summary: diagnostic -> guided practice -> active recall -> mixed review -> mastery check
